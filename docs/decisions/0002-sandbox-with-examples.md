# 0002: A sandbox with example queries first; challenges later

- **Status:** Accepted
- **Date:** 2026-10-05

## Context
The app should feel like a datadriven.io practice problem. That could mean guided challenges with checks, or just the look.

## Decision
v1 is a free-form SQL sandbox plus an **Examples** menu. Each example demonstrates one concept from *SQL Performance Explained* ([DATA.md](../DATA.md#example-queries-v1)). Guided challenges come later; the layout leaves room for a problem-statement panel.

## Consequences
Fastest path to something useful. Challenges can build on the examples later.

## Alternatives considered
- Sandbox only: less guidance for learners.
- Challenges first: needs a plan checker and authored content before the core visualization exists.
