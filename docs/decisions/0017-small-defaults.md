# 0017: Small defaults

- **Status:** Accepted
- **Date:** 2026-10-05

## Decision
- A replay/validation mismatch shows a warning banner; the animation still plays.
- The results pane shows up to 1,000 rows plus the total count.
- The OS "reduce motion" setting makes transitions instant; stepping still works.
- No analytics, tracking, or accounts.
- Supported browsers: current desktop Chrome, Edge, Firefox, Safari.
- Real Postgres terminology throughout, with glossary tooltips.
- Docs are kept current; each new or changed decision gets a record here.
